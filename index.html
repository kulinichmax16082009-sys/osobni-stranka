Projekty

Adventura „Sample Five”

Textová adventura podle vlastního game designu. Projekt zahrnuje kompletní dokumentaci a soubor README, načítání herních dat ze souborů ve formátu JSON, implementaci návrhového vzoru Command Pattern, využití vhodných datových struktur, debugging, vytvoření UML class a activity diagramů a sestavení výsledné aplikace do spustitelného JAR souboru.

Minesweeper Remake

Remake hry Minesweeper v jazyce Java s využitím knihovny Swing pro grafické uživatelské rozhraní. Hra obsahuje několik úrovní obtížnosti, možnosti nastavení, statistiky, zvukové efekty a hudební doprovod. Projekt dále zahrnuje objektově orientovaný návrh (OOP), ukládání herních dat a nastavení ve formátu JSON, dokumentaci README a sestavení výsledné aplikace do spustitelného JAR souboru.

NanoOmega

První rozsáhlejší textová hra v jazyce Java. Projekt zahrnuje dokumentaci a soubor README, načítání herních dat ze souborů a využití základních principů objektově orientovaného programování (OOP).
